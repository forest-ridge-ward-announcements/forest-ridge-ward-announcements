# Forest Ridge Ward Announcements

Static church announcements site intended for GitHub Pages.

## Announcement updates

Add, remove, or edit announcements in `announcements.json`. Use a `YYYY-MM-DD` date. The home page automatically sorts announcements by date and hides dates that have passed. Add a `url` when an announcement should link to a flyer or another page.

## Weekly bulletin update

Replace `bulletins/current-bulletin.pdf` with the new bulletin PDF. The bulletin page will display the replacement automatically.
